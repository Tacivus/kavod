Not solid. The graph, Journal machine, and A3/A4 mechanics hold. The holes are in live/sim as one contract, when a Port failure becomes a turn failure, and a few rows that contradict other rows.
Contradictions
1. shutdown after start Err cannot satisfy both sim rows
ENV-SERIAL: after any Err, the only later call is shutdown.  
SIM-START: the failing Port’s Err ends its lifecycle — no further call, stop included.  
SIM-SHUTDOWN: calls every Port’s stop.
Engine skips shutdown on start Err (RUN-FINALIZE / ENV-START), but the Environment contract is standalone. A caller who follows ENV-SERIAL (conformance suite, bespoke driver) double-stops successes and stops the failing Port. Live is merely unspecified for this call.
2. PORT-SUMS is claimed enforced; hand-written sums escape it
PORT-SUMS: sums are “type-checked against their Contracts.”  
Mechanism: hand-written equivalents are supported; “the macro is sugar, never authority.”  
Section 0: every ID outside Obligations is enforced.
A hand-written Primary(WrongType) compiles. The check lives only in ports!, which the doc says is not authority.
3. RUN-CHECKPOINT says every turn; handler/overflow Fatals never checkpoint
“Every turn observes the latch exactly once — after its last handoff … and before its completion record.”
TurnOpen: overflow or Outcome::Fatal discards the batch and goes to RUN-FINALIZE. No EffectsComplete, no take_error. Intent is “every completed turn.” The row is false as written.
4. Payload purity is cited into a table row that does not exist
App Notes: determinism rests on payload types carrying no hidden authority — “Application author’s trusted obligation (Obligations table).”  
Obligations row: Handlers and State only. Event/Command Drop, methods, interior mutability are absent. Completeness claim (“absent ⇒ enforced”) is then false. Same pattern: JRN-SINK assigns positioning/durability/destructor to the sink owner, and that work is not in the table.
5. §10 invents sim “time-domain exhaustion”; no SIM-* row defines it
Closed sim failures: nothing-armed, step-budget, TimeBeforeNow (Port-facing, not Env). now is assigned existing Timestamps — no overflow path. Live clock conversion does exhaust (LIVE-TIME). §10’s Error-sum shopping list does not match the closed contract.
Robustness holes
These rules are mutually consistent and still let the design fail.
6. Turn N’s Port failure can run turn N+1’s handler (live only) — the real break
Handoff ≠ processing:
 	Sim
dispatch commits at	on_command returns
cmd0 processing Err	latched before dispatch returns
Sim, 3-command batch, cmd0 fails: always Dispatch { position: 1 } (or Checkpoint if it is last). Suffix never handed off. Next Event never requested.
Live, same batch: publication can land before dispatch(c1), before dispatch(c2), at checkpoint, or after TurnCompleted(Continue). RUN-CHECKPOINT explicitly allows the last case. Then LIVE-SELECT may consume an already-queued Event (None “proves only that nothing was pending at the snapshot”). Turn N+1’s handler runs and mutates State. Journal says turn N succeeded. Fatal cause is attributed to turn N+1.
Not a DET-ENV violation (traces differ). It is A2/A4 as written: Engine turns are serial; live Port work is not bounded by the turn. Sim cannot exhibit this. Dual tests will not catch it.
7. “Emit stop-Commands, then Stop” is false on live recv
Run Notes present this as a derive.  
Sim: on_command is handoff — those Commands have fully run before StopRequested.  
Live: handoff is admission. ENV-SHUTDOWN lets the Port drain or abandon. recv (the primary API) reports shutdown ahead of queued Commands. The live obligation is only “observe the lifecycle and cooperate,” not drain.
Same Application intent, opposite Port effects. try_recv is optional.
8. Stopped does not mean no Port failed
Stop path: checkpoint None → StopRequested → shutdown closes the latch and discards pending. A Port error published after the snapshot is dropped. Run returns Stopped / Quiesced if threads join (LIVE-SUPERVISION: post-transition errors unpublished). Consistent with A4 (unobserved). Not robust: Stopped means “no latch-observing point saw an Error,” not “no Port failed.”
9. Idle and birth-death are not one Environment contract
- Nothing to wait for: SIM-COMPLETION → Environment(NextEvent) Fatal. LIVE-SELECT waits forever (BOUND-LOOPS exempts the wait). Zero slots is representable. Finite-source is a Ports Note, not a row. A finite LivePort that stops offering and blocks in recv deadlocks (Engine waits for Events, Ports wait for Commands, still Running).
- Port dies at birth: sim SimPort::start Err → Environment(Start), empty Journal, on_start never runs. Live run after gate publish → start Ok, RunStarted, on_start always runs, later Checkpoint/Dispatch/NextEvent.
DET-ENV only talks about equal traces, so it never fires. It also never describes which dual failures are even expressible as equal traces. Section 12’s “one conformance suite against both Environments” cannot populate these cases.
10. SIM-SELECT never binds the returned Timestamp
LIVE-TIME realizes ENV-TIME. No SIM-* row names ENV-TIME. SIM-SELECT advances now, clears the arm, calls step, and says only step(Some) creates the candidate — not that next_event returns (event, now) (or the arm time). A sim may stamp a constant (nondecreasing) and still satisfy every SIM-* row. Port now() and Application logical_time can disagree for the same candidate (A1 / “one Environment authority”).
11. Journal cannot do the forensic job the lead sentence assigns it
“Human-readable forensic evidence, guaranteed exactly through its last committed record” vs records carry “indices, times, Events, Commands, and outcomes and nothing else.” FatalCause and Quiescence live only in EngineExit. A8: panic ⇒ no exit.
Last record	Actually happened
EventAccepted / RunStarted	overflow, Application(E), handler panic, CommandsPrepared encode fail, kill
CommandsPrepared	dispatch fail at some k, all handed off then CommandsDispatched commit fail, abort mid-dispatch
StopRequested	ShutdownIncomplete, TurnCompleted(Stop) commit fail, panic in shutdown
The identifying sentence uses CommandsPrepared plus Dispatch { position }. After abort there is no exit, so no k. That is an unwitnessed-handoff window the Core creates (A5: completion record is after the last handoff). The business-key obligation is on the Application author; recognition of a repeated external effect is Port work (PORT-STATE). No Port-author row requires honoring the key. Same shape on input: consumed candidate + failed EventAccepted (TimeRegression / Journal) is gone, no Event-side key.
12. DET-ENV’s “so Journal bytes are Environment-independent” overclaims
DET-ENV is well-defined and almost vacuous: the trace already contains every Environment choice that changes discriminants. Equal traces ⇒ equal Engine behavior is “the Engine is Environment-agnostic,” not “live and sim are the same scenario.”
The connecting “so” (records have no Environment fields ⇒ DET-ENV) ignores that logical_time values are Environment-owned (ENV-TIME). Uncoordinated live/sim clocks diverge at RunStarted. Obligations also ban handlers from “Environment dependence” while logical_time’s meaning is Environment-dependent.
Other live-only Fatals with no sim image: inbox Full (backpressure kills the run; sim on_command cannot be Full), ShutdownIncomplete, premature run return. Sim-only: step budget, nothing-armed.
What held
Attacked and did not break:
- State/edge tables are complete: every Outcome, empty/nonempty batch, overflow, every Env/Journal fail, TimeRegression, IndexExhausted, ShutdownIncomplete has a path. No stuck state. Closed only via quiescence witness. No handler before acceptance.
- Index domain: 0 = start, EventAccepted advances; at index == u64::MAX next_event is uncalled. No off-by-one at u64::MAX.
- TimeRegression: consumed, not accepted, no index — consistent with glossary, RUN-INDEX, and the trace (start’s result and next_event’s result are in the trace; accepted sequence is not the whole trace).
- Empty-batch recordless edge is an intentional A5 exception (no effect to announce). §7’s “a transition is a commit” is sloppy intro, resolved by the edge table + Notes.
- Journal encode → write → flush → poison (Interrupted / Ok(0) / over-report) is internally tight. JRN-SINK vs OS durability is delegation, not a conflict.
- A4 no-rollback, overflow beating Outcome, Stopped ⇒ Quiesced, token affinity honesty paragraph, ENV-LATCH state machine (empty → pending → reported|closed) — consistent as written.
- Offer Full recoverable vs dispatch Full Fatal is justified (intent already journaled). The defect is only that sim cannot express dispatch Full.
If you want this robust
The expensive one is 6: live must not request the next Event while a previous turn’s handed-off work can still publish. Until that is a rule, sim is not a model of live failure, and DET-ENV will never say so.
Then: bind sim’s stamp to now; make shutdown after start Err a no-op (or forbid it); put payload/Drop/sink-owner duties in Obligations; enforce PORT-SUMS or demote it; fix RUN-CHECKPOINT’s quantifier; make finite-source + drain-on-Stop obligations (or change recv); put Fatal/prefix/quiescence in the Journal or stop calling the Journal forensic by itself.
